# 徽章圖示

放自訂的徽章 SVG。檔名對應 `src/lib/badges/icons.ts` 裡的 `file` 欄位。

## 怎麼換

1. SVG 放進這個資料夾，例如 `first-step.svg`
2. 到 `src/lib/badges/icons.ts` 給對應的徽章補上 `file`：

```ts
first_step: { emoji: '🌱', file: '/badges/first-step.svg' },
```

沒有 `file` 的徽章會繼續顯示 emoji，所以可以一個一個換，中途不會破圖。

## 畫的時候要注意

**尺寸**：用 `viewBox="0 0 128 128"` 設計，但實際顯示只有 **30px**（個人頁的徽章格、
解鎖通知列都是）。畫完務必縮到 30px 看一眼——細線條和小字在這個尺寸會直接消失，
形狀要夠大塊、輪廓要夠明確。

**亮底與深底都要能看**：徽章不吃 `currentColor`、也不跟主題色走（收藏品不該因為使用者
換主題就變色），代價是可讀性得由圖檔自己顧。同一張圖要同時站在 `#FFFDF5`（亮）和
`#15120D`（深）上，所以：

- 不要用純白或純黑當主要輪廓，其中一邊會消失
- 邊緣用中間調的顏色，或給圖一個自帶的圓形底盤

**未解鎖狀態**：`BadgeGrid` 會套 `grayscale` + `opacity-40`。設計時避免「只靠顏色區分」
的圖，因為灰階後那個區分就沒了。

**同一系列要看得出關聯**：`streak_3` / `streak_7` / `streak_30` 是同一條連續簽到的進階線，
三張圖應該像同一個東西的三個階段，而不是三個不相干的圖案。
